# Комплект зчитувача MOST для JLR

Тут лежить усе, щоб зробити зчитувач і з'їздити з ним, без решти репозиторію. Зчитувач стоїть
у кільці MOST25 машини, читає звук і команди керування, а віддає S/PDIF через TOSLINK. Зроблено
під Jaguar XF X250 за повідомленнями, які бачили відкриті проєкти; у машині ще не перевірено.

| Папка | Що всередині |
|---|---|
| `1_boards/` | замовлення плат на JLCPCB з монтажем SMD; деталі для ручного монтажу; схема, креслення монтажу, перевірки перед живленням |
| `2_fpga/` | прошивка FPGA (`reader.fs`) і як записати її в Tang Nano 20K з Windows або macOS |
| `3_laptop/` | програма запису поїздки й розбору вдома, для Windows 10/11 і macOS (і на Apple Silicon) |

## Порядок

1. **Плати.** Замовити за `1_boards/README.md` і окремо купити деталі для ручного монтажу.
2. **FPGA.** Ще до запаювання модуля Tang Nano 20K записати в нього `reader.fs`
   (`2_fpga/README.md`).
3. **Монтаж.** Запаяти ручні деталі, зробити перевірки перед живленням, увімкнути вперше
   (`1_boards/README.md`).
4. **Стіл.** Без ноутбука виміряти DARK і COLD. З ноутбуком провести тривалий тест лінії,
   на тому ноутбуці, що поїде (`3_laptop/README.md`, «Перед машиною»).
5. **Машина.** Спершу лише обхід: зчитувач у кільці, живлення є, а машина звучить як раніше.
   Далі зчитувач із записом.

## Звідки ці файли

Комплект збирає `tools/make_kit.py` з репозиторію. Файли плат, бітстрім і програми — це копії,
а пояснення (`README.md`) і файли запуску написано вручну. `check_all.py` падає, якщо копія
розійшлася з джерелом або якщо бітстрім старший за джерела FPGA. Коміт, з якого зібрано
бітстрім, записано у `2_fpga/BUILD.txt`.

Повні описи лежать у репозиторії: `README.md` (рішення і їхні причини), `reader_hw/README.md`
(плата), `reader_gw/README.md` (FPGA), `reader_gw/LOGGING.md` (запис).
